# Convey RPMs

Unofficial [Convey](https://gitlab.gnome.org/donnybeelo/convey) packages for Fedora 44 and Rawhide (x86_64).

```sh
sudo dnf copr enable grantson/convey
sudo dnf install convey
```

GitHub Actions checks for upstream changes weekly and builds updates in [COPR](https://copr.fedorainfracloud.org/coprs/grantson/convey/).
